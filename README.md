# Minigame 1
## Devlog
    The relationship between Components, GameObjects, and Scenes is like cooking a meal. Components add life and functionality to GameObjects. Which elevates them just like how seasoning enhances the flavor of food. GameObjects are the main ingredients in a scene, when they are given functionality they become objects that help flesh out a scene. Just like how multiple ingredients work together to create a full meal.
